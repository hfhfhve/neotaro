# NEOTARO

Сервис таро, сонника и нумерологии с ИИ-оракулом.
Работает как Telegram Web App и как сайт: **https://neotaro.ru**

## Что внутри

- **Таро** — расклады на 1, 3, 5 и 10 карт с интерпретацией через LLM
- **Сонник** — разбор символов сна по методу аналитической психологии, а не по таблице значений
- **Нумерология** — матрица судьбы, числа судьбы, зеркальные и ангельские числа
- **Совместимость** — разбор пар по знакам зодиака

## Технически

- Фронтенд — статика, деплой через Vercel, домен за Cloudflare
- Бэкенд — FastAPI, доступ через Cloudflare Tunnel
- Генерация интерпретаций — LLM через OpenRouter
- Авторизация — Telegram Web App initData, Google, VK ID, Яндекс ID
- Около 500 справочных страниц сгенерированы скриптами на Python с контролем уникальности по шинглам
